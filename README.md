# RIFT for desktop

Downloads and automatic updates for the RIFT desktop app. The app's source lives in a private
repository; this one only hosts the installers.

- **Mac** (Apple silicon and Intel, macOS 12+): `RIFT-mac.dmg`
- **Windows** (10 or 11, 64-bit): `RIFT-Setup.exe`
- **Linux** (64-bit): `RIFT-linux-x86_64.AppImage` or `RIFT-linux-amd64.deb`

Get them from the [latest release](https://github.com/NicolasMendesDev/rift-desktop/releases/latest)
or at [rift-eta-snowy.vercel.app/download](https://rift-eta-snowy.vercel.app/download).
